# Latar masalah (singkat)
Toko kecil, kantin, dan koperasi masih mencatat stok dan penjualan secara manual. Stok sering tidak cocok dengan barang di rak, dan pemilik sulit melihat omzet harian. Aplikasi ini mencatat produk, stok, dan transaksi dalam satu tempat.

# Target pengguna 1: Admin/Kasir (pengguna utama)

Contoh: Rina, 22 tahun, penjaga kasir toko kelontong.
Kemampuan teknis: dasar, terbiasa memakai HP dan aplikasi sederhana.
Perangkat: laptop atau PC kasir, kadang HP.
Tugas: input produk dan kategori, catat transaksi, cek dan perbarui stok.
Masalah: pencatatan di buku lambat, stok tidak ikut berkurang setelah penjualan.
Kebutuhan: form transaksi yang cepat, stok berkurang otomatis, pencarian produk, tampilan sederhana.

# Target pengguna 2: Pemilik (opsional)

Contoh: Pak Budi, 45 tahun, pemilik toko.
Kemampuan teknis: rendah, hanya ingin melihat hasil.
Perangkat: HP.
Tugas: memantau penjualan dan stok.
Masalah: sulit tahu transaksi hari ini dan barang apa yang hampir habis.
Kebutuhan: dashboard ringkas (total penjualan, transaksi hari ini, stok), tampilan nyaman di HP, filter tanggal.

# Kebutuhan pengguna menjadi fitur

Catat transaksi cepat → modul transaksi + detail transaksi
Stok akurat → pengurangan stok otomatis
Cari barang → pencarian produk
Pantau omzet → dashboard ringkasan
Akses aman → login, logout, session
